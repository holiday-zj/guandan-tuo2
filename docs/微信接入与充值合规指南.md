# 微信小程序接入 & 充值合规指南

> 本游戏为**掼蛋（拖2）**，属棋牌类，在微信生态内必须按**小游戏**（不是小程序）接入。
> 棋牌类是微信审核最严的类目之一，充值功能受国家法规强约束。请严格按本文档准备资质。

## 一、合规红线（先读这段，决定能不能充值）

| 能力 | 硬性前置条件 | 说明 |
|---|---|---|
| 注册小游戏账号 | **企业营业执照** | 个人主体**不能**注册小游戏、不能开微信支付 |
| 上线（免费玩） | 软著 + 棋牌类目资质 | 需《网络文化经营许可证》或地方棋牌备案，各地不同 |
| **开通充值** | **游戏版号（ISBN）** | 国家新闻出版署发；**棋牌类版号审批极严**，周期数月到数年 |
| 微信虚拟支付 | 版号 + 虚拟支付权限 | 仅**安卓**可用；**iOS 全面禁止**虚拟支付（苹果政策，无解） |
| 实名认证+防沉迷 | 法定强制 | 棋牌类必查，未成年禁止充值、限时 |

**核心结论：没有版号，微信端就不能开任何充值功能。** 这是平台+法规的硬规则，技术上无法绕过，绕过=封号+法律风险。

## 二、本项目的合规设计（已实现）

代码用**配置开关**兼容两条路，不会因资质卡住开发：

```
PAY_ENABLED=false（默认，无资质）
  → 充值接口全部返回"未开放"
  → 客户端自动降级为【每日免费领500币】模式，照样能上线运营

PAY_ENABLED=true（资质齐全后）
  → 微信虚拟支付（米大师）调起真实充值
  → 仅安卓；iOS 自动拦截
  → 未成年拦截、未实名拦截、单月¥500限额
```

已实现的合规控制（`server/pay.js`）：
- ✅ 未成年人禁止充值（实名认证后自动判定）
- ✅ 充值前强制实名（只存证件哈希，不存明文）
- ✅ iOS 虚拟支付拦截
- ✅ 单月充值限额 ¥500（防沉迷规定）
- ✅ 订单幂等（重复回调不会重复到账）
- ✅ 每日免费领取（无资质时的合规兜底）

## 三、你需要提供的信息（拿到后告诉我，我来配置）

### 第1步：微信登录（必需，先做这个就能上微信）
1. **小游戏 AppID**（`WX_APPID`）——微信公众平台注册小游戏后获得
2. **AppSecret**（`WX_SECRET`）——同上，后台"开发设置"里

### 第2步：充值（需版号后才能启用）
3. **虚拟支付 AppKey**（`WX_MIDAS_APPKEY`）——开通虚拟支付后获得
4. **虚拟支付 offerId**（`WX_MIDAS_OFFER_ID`）——同上

### 第3步：上线部署
5. **已备案域名** + 服务器（微信强制 HTTPS/WSS）
6. SSL 证书（可用免费的 Let's Encrypt）

## 四、配置方法（拿到资质后）

环境变量启动即可，无需改代码：

```bash
# 微信登录（拿到 AppID/Secret 即可启用）
WX_APPID=wx1234567890abcdef \
WX_SECRET=*** \
node server/index.js

# 充值（额外需要版号+虚拟支付，且 PAY_ENABLED=true）
WX_APPID=... WX_SECRET=*** \
WX_MIDAS_APPKEY=*** WX_MIDAS_OFFER_ID=123456 \
PAY_ENABLED=true \
node server/index.js
```

生产环境建议用 `.env` 文件或 systemd Environment 管理，**不要硬编码进代码**。

## 五、微信开发者工具导入步骤

1. 微信开发者工具 → 导入项目 → 选择 `client-wechat/` 目录
2. AppID 填你的小游戏 AppID（没有可先用"测试号"）
3. 改 `client-wechat/js/net.js` 顶部 `BASE`/`WS` 为你的服务器地址（上线必须 HTTPS/WSS）
4. 详情 → 本地设置 → 勾选"不校验合法域名"（仅开发调试）
5. 上线前：微信公众平台后台配置 request/socket 合法域名

## 六、建议的落地顺序

1. **现在**：网页版 + 免费模式（每日领币）已可玩，先内测收反馈
2. **拿到企业主体**：注册小游戏、申请棋牌类目、软著 → 上微信（免费模式）
3. **拿到版号**：开通虚拟支付 → `PAY_ENABLED=true` → 充值上线
4. 全程：实名认证接口需替换为国家新闻出版署**权威核验接口**（当前为格式校验演示版）

## 七、当前接口清单（已实现并测试）

| 接口 | 用途 |
|---|---|
| `POST /api/wx/login` | 微信 code 登录（无资质时优雅降级） |
| `GET /api/pay/packages` | 充值档位 + 开关状态 + 每日领取状态 |
| `POST /api/pay/daily` | 每日免费领币（幂等，每日一次） |
| `POST /api/pay/create` | 创建充值订单（合规拦截：无资质/iOS/未成年/未实名/超限额） |
| `POST /api/pay/notify` | 米大师支付回调（生产需验签） |
| `GET /api/pay/orders` | 充值订单记录 |
| `POST /api/verify` | 实名认证（成年判定） |

测试：`node test/pay.test.js`（11项）、`node test/wx-login.test.js`（降级）全通过。
